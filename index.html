SPM 表贴式永磁同步电机 · FOC 矢量控制原理演示

id=0 控制 | 6线圈径向分磁场（正向指向圆心）→ 合成Fs | Ld≈Lq 仅永磁转矩 | p=1

FOC 坐标变换公式

① Clark 变换（ABC → αβ，等幅值）
iα = ia
iβ = ( ib − ic ) / √3
② Park 变换（αβ → dq）
id = iαcosθe + iβsinθe
iq = −iαsinθe + iβcosθe
③ 反 Park 变换（dq → αβ）
iα = idcosθe − iqsinθe
iβ = idsinθe + iqcosθe
SPM 特性：Ld ≈ Lq，磁阻转矩 ≈ 0，仅永磁转矩
转矩方程：Te = 1.5 · p · ψf · iq（id = 0 时，Te ∝ iq）
提示：拖动"电角度 θe"滑杆可定格逐点讲解；线圈磁场为径向——正向电流指向圆心、反向背离圆心，6 线圈瞬时叠加 → 大小/方向可调的 Fs（id=0 时 Fs 与 q 轴同向）。转子仅 N/S 色块，无任何转子永磁磁力线。
